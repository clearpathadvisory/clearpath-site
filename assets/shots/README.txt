HOW IT WORKS
------------
Name the file after the product. A file that is present shows; a file
that is missing falls back to the CSS mockup. No code to change.

SIZE
----
620 x 1300, portrait. Anchored to the top of the phone screen and
cropped from the bottom, so put the interesting part high in frame.
Trim the iOS status bar and any browser chrome first.
